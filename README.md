# FitnessCore Pro

## О проекте
FitnessCore Pro — это информационная система, разработанная для автоматизации деятельности фитнес-клуба. Система позволяет администраторам вести учет клиентов, регистрировать их в базе данных и управлять продажей абонементов с автоматической проверкой актуальности статусов.

## Функциональные возможности
* **Управление клиентами**: Полный цикл CRUD-операций: регистрация новых пользователей, просмотр списка и удаление записей.
* **Управление абонементами**: Умная логика подписок — система автоматически деактивирует предыдущие абонементы при покупке нового, предотвращая дублирование услуг.
* **Валидация данных**: Встроенная система контроля ввода данных (например, для телефонных номеров), обеспечивающая целостность базы данных.
* **Современный интерфейс**: Адаптивный дизайн, выполненный на базе Bootstrap 5, обеспечивающий удобство работы администратора.

## Стек технологий
* **Язык**: Python 3.x
* **Веб-фреймворк**: Flask
* **База данных**: SQLite
* **Фронтенд**: HTML5, CSS3, Bootstrap 5, Chart.js
